# Scout Collector の入れ方

1. この `extension` フォルダをPCへ保存します。
2. Chromeで `chrome://extensions/` を開きます。
3. 右上の「デベロッパーモード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押します。
5. この `extension` フォルダを選びます。
6. しまむらオンラインの商品一覧を通常どおり開きます。
7. Chrome右上の拡張機能から「Shimamura Export Scout Collector」を押します。
8. 巡回範囲を選び、「自動巡回スキャンを開始」を押します。
9. 別タブの進捗画面を完了まで開いたままにします。全ページを選ぶと、商品がなくなるページまで自動で進みます（安全上限500ページ）。

ログイン情報やCookieはScoutへ送信しません。各商品一覧から抽出した商品名・価格・URL・画像URLだけを送信します。
